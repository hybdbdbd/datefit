# 데이트핏 (DateFit)

진주·김해 데이트 코스 추천 데모입니다. 2026 동남권 대학생 창업경진대회(A트랙) 출품용으로 만들었습니다.

- 날짜·시간·이동수단·음주 여부 같은 조건을 고르면, 등록된 영업시간과 이동 시간을 반영한 코스와 시간표를 보여줍니다.
- 코스 상세 화면에서 TMAP 지도 위에 장소 순서와 길찾기 경로를 표시하고, "내 위치" 버튼으로 첫 장소까지 가는 도보 경로를 볼 수 있습니다.
- 장소 정보는 2026년 11월 8일 카카오맵 기준이며, 그 뒤로 바뀌었을 수 있습니다.
- 지도·위치·경로 데이터는 TMAP API에서 열 때마다 받아오며, 약관에 따라 24시간 넘게 저장하지 않습니다.
- 로그인이나 서버가 없는 데모로, 기록과 스티커는 각자의 브라우저에만 저장됩니다.
